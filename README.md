# Adri Nails Nail Studio

Sitio web profesional para **Adri Nails**, un estudio de uñas ubicado en Caracas, Venezuela. Presenta servicios, precios en euros y bolívares, trabajos reales, horarios y contacto directo por WhatsApp e Instagram.

## Funciones

- Catálogo de siete servicios con precios en euros.
- Conversión automática a bolívares mediante la tasa oficial del euro del BCV.
- Fecha visible de actualización de la tasa.
- Galería con trabajos reales de Adri Nails.
- Reserva por WhatsApp con mensaje preparado para cada servicio.
- Horarios de atención y modalidades en estudio o a domicilio.
- Enlace y código QR de Instagram.
- Diseño responsive para teléfonos y computadoras.
- Fallback local para conservar la última tasa disponible si falla la consulta.
